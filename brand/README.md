# SHAMS Holding brand

**Motif:** *der rote Faden*, one continuous red thread. The mark is that thread drawn as an "S".

| Token | Light | Dark |
| --- | --- | --- |
| Red (accent) | `#C8102E` | `#E3263F` |
| Ink | `#141414` | `#F1EDE6` |
| Paper | `#FAF8F5` | `#0F0E0D` |
| Muted | `#6B6762` | `#9B958D` |

**Type:** Instrument Serif (headlines), Inter (text, wordmark). Both SIL OFL, self-hosted.

**Rules**
- Red is used for the thread and nothing else that competes with it: one red element per view.
- Lots of paper. No gradients, no shadows, no stock imagery.
- The thread never cuts through text.
